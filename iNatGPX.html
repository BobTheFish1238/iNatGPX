How do I get the export?
  1. Open iNaturalist export
  2. Select your place and taxon
  3. Set geoprivacy and taxon_geoprivacy to open. Example query:
    quality_grade=any&identifications=any&geoprivacy=open&taxon_geoprivacy=open&place_id=46&taxon_id=48703
  4. Enable only these columns: observed_on_string quality_grade url latitude longitude positional_accuracy scientific_name common_name taxon_id
  5. Export and download the zip file
